## Maintenance rules

* Keep one canonical document per topic. Label older versions clearly until they can be verified before archiving.
* Preserve technical meaning and source links when correcting spelling, headings, or formatting.
* Do not invent missing facts. Flag unclear or conflicting information for review.
* Keep working notes, course material, policies, and approved procedures distinguishable.
* Review likely duplicates and empty placeholders before deleting or merging them.
